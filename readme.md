THE MOD:

Forager: Allows pals with the gathering skill to uproot and forage berries, mushrooms and more! No longer shall free food go ungathered. Made because I wanted to be able to harvest the mushrooms in the red forest with that them eagle fellas in the earlygame, it works with most plant-like things you would normally have to press F on to pick up. Any pal with the gathering skill will automatically "Forage" when idle as a job task if they have the right level to forage the item, berries need level 1 gathering, mushrooms level 2, etc. (These numbers are editable in the config)
